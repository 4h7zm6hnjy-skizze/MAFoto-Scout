CampManager – Vollversion

Die Web-App läuft vollständig aus einer einzigen index.html.

Enthalten:
- Nächste Anreise
- Offene Einkäufe
- Kostenübersicht ohne Lebensmittel/Ausflüge
- Petroleum: Einkauf, Verbrauch, Bestand
- Strom nur als Jahreswerte: Verbrauch, Stromkosten, Zählermiete
- Übernachtungszähler
- Rasenpflege
- Heckenschnitt: maximal 2 Einträge pro Jahr
- Verträge mit Fristen und Jahreskosten
- Gasprüfungen mit nächstem Prüftermin
- Familienmitglieder
- Stellplatzdaten
- Fristen auf dem Dashboard
- JSON-Backup/Import
- Optionaler Familien-/Mehrgeräte-Sync über Supabase
- Keine externe JavaScript-Bibliothek erforderlich

Für GitHub Pages reicht es, index.html im Repository zu ersetzen.
Das vorhandene logo.jpg wird weiterverwendet.

Cloud-Sync:
1. Kostenloses Supabase-Projekt anlegen.
2. supabase.sql einmal im SQL Editor ausführen.
3. In CampManager unter Zahnrad die Project URL + Anon/Public Key eintragen.
4. Familienkonto erstellen.
5. Auf allen Geräten mit demselben Familienkonto anmelden.
